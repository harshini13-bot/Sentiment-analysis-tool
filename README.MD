# Sentiment Analysis Tool

## Overview

This project performs sentiment analysis on user reviews using Machine Learning.

The model is trained on labeled review data and predicts whether a review is positive or negative.

## Features

* Text Preprocessing
* TF-IDF Vectorization
* Naive Bayes Classification
* Interactive Streamlit Interface

## Technologies

* Python
* Streamlit
* Pandas
* Scikit-Learn

## Run

python train_model.py

streamlit run app.py
